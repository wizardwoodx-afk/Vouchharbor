# VH 17.10.9 — Agentic Product Layer

This release turns the existing mission/team/security substrate into the product layer requested for pre-seed launch.

- VH-19 is the direct-to-user generalist/head.
- A VH-owned registry exposes 512 specialist entries and routes tasks autonomously by capability, risk, benchmark, and security score.
- User 1 can invite User 2; the collaboration is pending until User 2 explicitly approves it.
- Approved collaborations retain task-scoped Team-Evolve memory.
- User acceptance/rejection is captured as explicit preference signals with optional reasons.
- Calibration exams are generated from observed task patterns; the user marks the agent answer Correct/Wrong.
- >=90% makes the relevant task category eligible for autonomous mode. Lower scores return/remain in supervised mode.
- Autonomy is category-scoped and revocable.
- Mastra, VoltAgent, and Vercel AI SDK are integrated behind VH-owned adapter boundaries. Upstream source could not be fetched in the no-network build environment, so only import manifests are vendored in this archive; no third-party source is falsely represented as copied.
